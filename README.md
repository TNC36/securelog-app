## 📋 Project Overview

**SecureLog** is a decentralized security incident management system built on the **Avalanche Fuji Testnet**. It allows security teams and organizations to record, track, and verify security incidents on the blockchain, ensuring **immutability, transparency, and accountability**.

### 🎯 Problem Statement
Traditional security incident logs can be tampered with, deleted, or manipulated. There's no way to prove when an incident was reported or who reported it. SecureLog solves this by leveraging blockchain technology to create an **immutable, timestamped, and transparent incident log**.

### 💡 Solution
- ✅ **Immutable Records** - Once recorded, incidents cannot be altered or deleted
- ✅ **Timestamped Proof** - Every incident has a verified timestamp on the blockchain
- ✅ **NFT Badge Rewards** - Gamified system rewarding top security contributors
- ✅ **Decentralized Storage** - Evidence files stored on IPFS
- ✅ **Real-time Analytics** - Visual insights into incident patterns

## ✨ Features

### 🎨 Visual Features
- **5 Stunning 3D Backgrounds** - Click the color dots in bottom right to switch between:
  - 🔶 Floating Blockchain Cubes
  - 🌌 Particle Galaxy
  - 💫 Rotating Rings
  - 🔗 Blockchain Network
  - 🌊 Aurora Waves

### 🔐 Web3 Features
- **Wallet Integration** - Connect with Core Wallet or MetaMask
- **Multi-Language Support** - English, Español, हिंदी
- **NFT Badge System** - Earn badges for reporting critical incidents:
  - 🥉 **Bronze Guardian** - Report 1 critical incident
  - 🥈 **Silver Sentinel** - Report 3 critical incidents
  - 🥇 **Gold Guardian** - Report 5 critical incidents

### 📊 Analytics & Reporting
- **Incident Categories** - Phishing, Malware, Unauthorized Access, Data Breach, DDoS, Insider Threat
- **Severity Levels** - Critical, High, Medium, Low with color-coded badges
- **Real-time Charts** - Visual representation of incident distribution
- **Top Reporters Leaderboard** - Track top security contributors

### 📎 Additional Features
- **File Evidence Upload** - Attach screenshots, logs, or PDFs as evidence
- **Dark/Light Mode** - Toggle theme for comfortable viewing
- **Responsive Design** - Works on desktop, tablet, and mobile
- **One-Click Export** - Download incident reports as JSON
